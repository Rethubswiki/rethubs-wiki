# Taxonomía editorial

Estos archivos proporcionan vocabulario para organizar fichas ya revisadas. **No sustituyen** el contrato en `schemas/resource-record.schema.json`, que continúa definiendo los campos públicos permitidos, las plataformas, los estados de revisión y la estructura de evidencia.

Cada ficha conserva un único valor `kind` compatible con el esquema. La categoría y las subcategorías se usan para navegación y propuestas; nunca autorizan una publicación por sí solas. Las etiquetas recomendadas solo pueden aplicarse si una fuente pública incluida en `evidence` respalda la afirmación.

Las propuestas pendientes, datos de moderación, notas privadas y preferencias locales quedan fuera de esta taxonomía pública.
