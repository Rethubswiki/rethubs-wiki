# Start Here

> Rethubs Wiki is an evidence-aware map for open-source entertainment tools. It helps readers orient themselves; it does not certify a service, a source, a jurisdiction, or a future release.

**Tags:** [orientation](Tags-and-Discovery#editorial-pages) · [policy](Tags-and-Discovery#editorial-pages)

## Read an entry before acting

Each resource entry records a canonical origin, a role, a review date and an evidence label. A label is deliberately narrower than a recommendation:

| Label | Read it as |
|---|---|
| **Declared** | The project itself states the field. |
| **Observed** | A reviewer recorded a dated canonical observation. |
| **Inferred** | A limited interpretation that should not be expanded into a promise. |
| **Unconfirmed** | The available evidence does not support the claim. |

Use the [Resource Entry Template](Resource-Template) to understand the structure. If an entry does not show the information you need, treat it as missing rather than filling the gap with an assumption.

## Boundaries

Rethubs does not host installers, media, credentials, personal browser data or private review notes. A discovery directory can be credited for helping locate a project, but only a project’s canonical material can establish its own project facts. The [Sources and Attribution](Sources-and-Attribution) page records those discovery credits and their limits.
