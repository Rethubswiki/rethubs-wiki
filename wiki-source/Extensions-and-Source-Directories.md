# Extensions and Source Directories

> An extension, a source directory and a host application are different things. This page makes that boundary visible before an entry is read as an installation instruction.

**Tags:** [extension](Tags-and-Discovery#resource-type) · [source](Tags-and-Discovery#resource-type) · [directory](Tags-and-Discovery#resource-type)

| Term | Rethubs meaning | Required record |
|---|---|---|
| Extension | A component used by a declared host app or version family. | Host, relationship source, platform and compatibility label. |
| Source | A technical route or catalogue consumed by a compatible project. | Canonical source and explicit boundary; no assumed availability. |
| Directory | A site that helps discover software, guides or links. | Attribution and a note that it does not prove every listing. |
| Store | A distribution surface. | Store name, project source when available and a separate review of the individual app. |

## Compatibility is never inherited

If a directory lists a project, that does not establish that an extension works with a particular host. If a project is open source, that does not establish the license or safety of every source a user may add. Rethubs records the narrow relationship that can be cited and labels the rest **unconfirmed**.
