# Visual Language and Accessibility

> The visual language helps people navigate evidence; it is never evidence itself.

**Tags:** [orientation](Tags-and-Discovery#orientation) · [accessibility](Tags-and-Discovery#accessibility) · [community](Tags-and-Discovery#community)

Rethubs uses a marine–stellar interface language for the public reference: cerulean and deep-ocean surfaces, route-like lines, soft rounded reading panels and **La Pequeña Ballena Celeste** as an orientation marker. This vocabulary creates a calm entry point without mixing the independent Spanish community, English community and Miyomi operations editions.

## Semantic use of the visual system

| Element | Meaning | Must not imply |
|---|---|---|
| Cerulean route | Navigation, discovery or locally selected state | Project verification, safety or editorial approval |
| Whale marker | The Rethubs orientation layer | Sponsorship, certification or a recommendation |
| Soft panel | A bounded reading or input surface | A confidential or locally stored record by itself |
| Coral or glacial edition cue | The independent Operations or English edition | A cross-link, shared audience or common editorial scope |

The catalog’s provenance labels, review date, canonical link and declared compatibility remain the authoritative signals. Color and illustration only reinforce hierarchy.

## Accessible interaction boundary

The public interface must preserve keyboard focus, meaningful labels for search and navigation, a visible state for the day/night control, and text alternatives for non-decorative media. Decorative stars, waves and whale illustrations must be hidden from assistive technology or supplied with a concise purpose-specific label.

Motion is optional. Transitions should stay brief, operate through opacity or transforms, and respect the operating system’s reduced-motion preference as well as the visitor’s local setting. Regional display choices, download profile and motion preference remain local to the browser; they are not location tracking and must not be sent to the editorial queue.

## Editorial boundary

This visual language does not change the publication process. A proposal still needs a canonical source and human review before it can alter a published resource page. Email remains opt-in, and publishing to a repository remains a separately confirmed action.
