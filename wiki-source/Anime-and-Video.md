## Read the categories before a listing

| Category | What it may contain | What it cannot establish alone |
|---|---|---|
| Client | A project that plays or organizes material. | The availability of a particular work or service. |
| Server | Software for a library controlled by the operator. | A public source of works, extensions or subscriptions. |
| Extension | A component whose host-app and version relationship must be declared. | Broad compatibility across unrelated clients. |
| Index or directory | A discovery path with attribution. | Authorship, safety, maintenance or compatibility for every linked project. |
| Guide | Setup notes limited to their cited version and platform. | A guarantee that the same steps remain current. |
