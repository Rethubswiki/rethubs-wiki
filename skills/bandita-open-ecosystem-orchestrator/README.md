# Orquestador del ecosistema abierto de La Bandita

Este directorio conserva la copia versionada de la **mega habilidad modular** que coordina el mantenimiento de La Bandita y Rethubs Wiki. No sustituye la revisión editorial ni automatiza decisiones de publicación; transforma solicitudes amplias en carriles verificables de catálogo, experiencia local, comunidad, S+, GitHub y entrega.

## Contenido

| Ruta | Propósito |
|---|---|
| `SKILL.md` | Punto de entrada: contrato, selección de carril, secuencia de trabajo y cierre verificable. |
| `references/editorial-evidence.md` | Criterios de fuente canónica, licencia, actividad, atribución y estado `needs-review`. |
| `references/local-first-experience.md` | Privacidad local, accesibilidad, aislamiento de ediciones, participación y rendimiento móvil. |
| `references/splus-governance.md` | Límites, cadencia y cola humana para auditoría y descubrimiento S+. |
| `references/publication-bridge.md` | Ramas, PRs, fusión autorizada, verificación de `main` y protección de secretos. |
| `templates/review-brief.md` | Plantilla para presentar alcance, evidencia, validación, exclusiones y decisión solicitada. |

## Uso y actualización segura

Actualizar primero la copia de trabajo de la habilidad y validarla antes de reflejarla aquí. Esta copia pública debe excluir secretos, datos de sesión, correos personales, IDs operativos privados y registros de usuario. Su actualización remota se somete al mismo proceso de rama, validación y confirmación específica antes de fusionar.

La habilidad remite a las guías especializadas ya existentes cuando un cambio necesita catalogación, automatización, conectores, integración de IA o desarrollo web. Esa división conserva el contexto necesario sin duplicar reglas contradictorias.
