## Updating safely

Before changing this skill, confirm the behavior of relevant primary sources, including the official [GitHub MCP Server](https://github.com/github/github-mcp-server). Update the installed working copy and this versioned copy in the same review branch, validate the skill, and request human approval before merging or publishing.

Never commit API keys, OAuth data, email recipients, personal records, or shared-access links.
